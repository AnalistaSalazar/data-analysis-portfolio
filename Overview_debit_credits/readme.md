# Third-Party Debits and Credits Dashboard

## Overview

The **Third-Party Debits and Credits Dashboard** is an interactive Power BI report designed to monitor and analyze financial transactions involving third parties. It provides a clear overview of total debits, credits, balances, spending trends over time, and the accounts and third parties with the highest transaction volumes.

The dashboard enables finance teams to quickly identify significant movements, monitor account balances, and support financial decision-making.

---

## Objectives

* Monitor total debits, credits, and balances.
* Identify the third parties with the highest debit transactions.
* Analyze monthly financial trends.
* Compare debits and credits by account.
* Improve financial visibility and reporting efficiency.

---

## Dashboard Features

### KPIs

The dashboard includes three key performance indicators:

* **Total Debits**
* **Total Credits**
* **Current Balance**

These KPIs provide an instant overview of the organization's financial position.

---

### Top 5 Debits by Third Party

Displays the five third parties with the highest debit amounts, allowing users to quickly identify the largest financial outflows.

---

### Financial Trend Analysis

A time-series visualization showing:

* Total Debits
* Total Credits
* Balance

This chart helps users identify seasonal trends, unusual spikes, and monthly financial behavior.

---

### Debits and Credits by Account

A detailed table presenting:

* Account Description
* Total Debits
* Total Credits

This section allows for detailed financial analysis at the account level.

---

## Filters

Users can filter the report by:

* Year

These filters allow for flexible exploration of financial data across different time periods.
